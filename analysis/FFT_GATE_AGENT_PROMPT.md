## 实施目标

保留现有底噪、相对能量门限、预录、传输格式和异常兜底，在能量判断后增加一层频谱筛选：

1. 第一版只用谱平坦度和归一化谱熵作候选准入，两个条件均通过。
2. 筛选参与起音累计，也参与录音期间的“活跃”判断：仅响度高但频谱不通过的帧，不能继续按有效语音抵扣静音时间。
3. 不删除、重排或改写原始音频；预录/段内发送依旧保持既有序列。没有通过门限不等于立即丢音或单帧切断录音，继续使用时间累计与尾部宽限。
4. 参数集中配置，提供总开关；关闭时应完全保持旧算法行为。启用路径必须实际接入起止判定，不只打日志。默认是否启用及实测边界在交付中写清楚。
5. 不引入F0/YIN、神经网络或多个重复特征。300–4000 Hz能量比例先作为可观察指标，不作为第一版强制门槛，其候选下限0.0003（0.03%）过宽，辨别价值尚未证明。

候选通过范围：
- 谱平坦度 <= 0.199
- 归一化谱熵在 [0.070, 0.809]

重要：这些是365条人声录音中51557个RMS>=-50 dBFS完整帧的宽分位边界，不是噪声分类器的已验证阈值；-50 dBFS仅用于离线选取统计帧，不得新增为产品固定起音门限。没有逐帧语音真值，也没有本轮噪声对照。原先96.92%的帧保留率是包含频带比例在内的三个特征组合结果，不能直接当作两特征实现的保留率或语音召回率，应重新计算。

必须保持或重新标定的计算口径：
- 16 kHz；20 ms帧、320 samples；20 ms步长；逐帧去均值后乘周期Hann窗。
- 原分析为320点FFT，单边PSD，DC/Nyquist不加倍，其余频点乘2；PSD=|FFT|²/(16000*sum(window²))。
- 谱平坦度仅用50–8000 Hz：PSD几何均值/算术均值；log前截到1e-30 FS²/Hz。
- 谱熵用同频段归一化PSD的 `-sum(p*ln(p))/ln(160)`。零能量、非有限值需明确处理，不得产生NaN传播。
- 若ESP-DSP要求512点FFT，可将同一320点加窗数据补零至512，但频点数、频段选择、归一化均会改变。必须用同批数据按新口径重算门限和保留率，不能硬套320点门限，也不能继续固定ln(160)。记录选择理由和最终参数。
