# S4 未起音退出（2026-09-17）

## 实机问题

COM8 记录到唤醒词进入 S4 后没有产生对话段 LC_START，60.01 秒后由监听兜底
断开 WSS，再经 S7 断联提示返回 S3。不是活动音频段无法收尾。
日志：`build-host-state-recovery/s4-live-diagnosis.log`。

## 行为

- 仅 S4 启用：唤醒词和 IMU 共用；S1、S2.1 保持现有行为。
- 提示音、防回声及 capture_ready 门控放行后，累计处理 250 个 20 ms 监听帧。
  门控关闭时清零等待累计；缺失的采样帧不按墙钟补算，因此异常采音停顿仍由原 60 秒兜底处理。
- 复用现有能量、FFT、VAD 联合起音判断；零星通过帧不续期。
- 第 250 帧先判断起音；达到起音条件优先开始正常音频段，取消本轮未起音退出。
- 未起音到期产生本地 LC_IDLE_TIMEOUT，不序列化为 capture_end，不生成虚假音频段。
- FSM 按状态 revision 校验后处理 EVT_LISTEN_IDLE_TIMEOUT，S4 正常转到 S3。
  云端通过现有 device_state 同步获知状态；正常退出保留连接，不播放断联提示。
- 通知发出后，当前窗口暂停起音，防止排队期间又开始上传。状态版本变化重开窗口，
  迟到通知由 FSM owner 丢弃；新 S4 清掉旧唤醒候选段和预录。
- 保留现有段尾、15 秒截段及 60 秒监听异常兜底。通知入队失败仍走会话故障恢复。

S2.1 在当前本地采集路径由起音推进，因此不额外增加未起音期限。
被联合门控接受的电视人声等仍会开始音频段；本改动不识别说话人或对话意图。
