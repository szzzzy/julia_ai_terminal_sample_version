# S4 本地唤醒应答

2026-09-17。仅修改固件；云端已由用户去掉唤醒应答 TTS 与音频下发，本次未修改或重启云端。

## 时序

当前本地收音配置收到通过设备、会话、轮次校验的 `wake_detected` 后，同步提交 S4，随即启动内嵌 WAV。原有 `state_ready` 由 WSS owner 发送，不等音频播完。云端可在本地应答期间准备后续对话；按用户确认，不新增云端就绪回信或固定等待，也不新增播放完成报文。

资源为根目录 `wake_prompt_16k_mono_16bit.wav`：16kHz、单声道、16bit PCM，31,488 样本，时长 1.968 秒。复用本地 WAV 播放与嘴型通路，跳过网络音频的 1 秒预缓冲。普通 S2 回答仍使用原网络播放缓冲。

首句在应答之后开启。S4 提交至播放器启动之间、播放期间、现有约 600ms 防回声间隔内以及 S4 回执尚未成功发送时保持收音关闭；之后继续 capture-v1。没有应答期间抢话或云端准备超时的首句补传机制，云端需在这一时间内准备好接收。

重复或过期唤醒不重播。迟到的云端唤醒 SPKS 被拒绝，PCM 与 SPKE 不干扰本地应答。离开 S4 或断线取消应答，旧播放代次不能结束新一轮；应答启动或输出失败走会话恢复。
